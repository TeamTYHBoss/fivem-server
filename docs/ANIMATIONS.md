# Animations

`whellco_animations` adds working animations for players, including different walks, smoking, drinking, and other animations.

## Walk animations

- Confident walk.
- Business walk.
- Casual walk.
- Gangster walk.
- Tough walk.

## Smoking animations

- Smoke animation.

## Drinking animations

- Drink animation.

## Gesture animations

- Wave animation.
- Facepalm animation.
- Thumbs up animation.
- Dance animation.

## Commands

Play a walk animation:

```text
/anim walk 1
```

Play a smoking animation:

```text
/anim smoking 1
```

Play a drinking animation:

```text
/anim drinking 1
```

Play a gesture animation:

```text
/anim gestures 1
```

Stop the current animation:

```text
/stopanim
```

View animation help:

```text
/animlist
```

## Controls

| Control | Action |
|---|---|
| X | Stop the current animation |

## Security

- Animation commands are client-side.
- Animation dictionaries are loaded client-side.
- Animation playback is client-side.
- Animation stopping is client-side.
